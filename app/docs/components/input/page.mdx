## Renderable API

<CodeBlock
  title="renderable"
  code={`import { InputRenderable, InputRenderableEvents, createCliRenderer } from "@opentui/core"

const renderer = await createCliRenderer()

const input = new InputRenderable(renderer, {
  id: "name-input",
  width: 25,
  placeholder: "Enter your name...",
})

input.on(InputRenderableEvents.CHANGE, (value) => {
  console.log("Input value:", value)
})

input.focus()
renderer.root.add(input)`}
/>

## Construct API

<CodeBlock

## Focus states

The CHANGE event is emitted after text insertion and deletion operations, and when assigning a different `value`. The listener receives the current value.

## Password fields

Style an input as a password field with a masked value:

<CodeBlock
  code={`const passwordInput = Input({
  id: "password-input",
  width: 20,
  placeholder: "••••••••",
  backgroundColor: "#222",
  focusedBackgroundColor: "#333",
  textColor: "#FFF",
  cursorColor: "#0F0",
})

const mask = (value: string) => "•".repeat(value.length)

// Hook into change events to render the masked value
passwordInput.on("change", (value) => {
  console.log("typed:", value)
})`}
/>

## Tab navigation

Add tab navigation between multiple inputs:

<CodeBlock
  code={`const inputs = [usernameInput, passwordInput]
let focusIndex = 0

renderer.keyInput.on("keypress", (key) => {
  if (key.name === "tab") {
    focusIndex = (focusIndex + 1) % inputs.length
    inputs[focusIndex].focus()
  }
})`}
/>
